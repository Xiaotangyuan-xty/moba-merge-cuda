## 新接口与支持范围

```python
from moba_opt.api import run_impl

# Q:[T,Hq,D], K/V:[T,Hkv,D], Hq % Hkv == 0
out = run_impl("opt_gqa_cuda", q, k, v, cu, max_seqlen,
               {"chunk_size":128, "topk":4})

# 正确性对照：显式复制完整 K/V，再调用冻结官方 MoBA；复制参与 autograd。
ref = run_impl("official_gqa_repeat", q, k, v, cu, max_seqlen,
               {"chunk_size":128, "topk":4})
```

旧 `official`/`opt_merge_cuda`/`opt_merge_atomic` 入口仍按 MHA 校验；原生 grouped 使用独立入口。

| 项目 | 当前支持契约 |
|---|---|
| heads | MHA/GQA/MQA，Hq 是 Hkv 的正整数倍，相邻 query 头分组共享 KV 头 |
| D | 8..256，且为 8 的倍数；包括 24/40/80/96/160/192/224 等非 2 的幂维度 |
| dtype | Attention 为 BF16/FP16，Q/K/V dtype 相同 |
| device/layout | Q/K/V/cu 同一 CUDA 设备，最后一维连续，cu 为连续一维 int32 |
| 序列 | 非空 packed-varlen，Q 与 KV 的总 token 数相同，支持不均匀序列与尾块 |
| max_seqlen | 等于实际最大序列长度 |
| config | 正整数 chunk_size；topk=1..9；causal=True、dropout=0 |
| fallback | 保留固定版本 K=1 或无历史候选时的整条序列 dense causal FA |

这些是算子形状支持，不等于完整模型接入或质量评估。MoBA 不能因此被宣称为任何预训练模型的无损替换。

## 原生 KV 共享的设计

设 G=Hq/Hkv，query 头 h 对应 KV 头 floor(h/G)。

1. 块均值按 Hkv 计算，仅将小型块代表 `[F,Hkv,D]` 扩展到 Hq，保持逐 query-head 路由；没有扩展整份 token K/V，也不复制 V 来做路由。
2. 当前块直接调用 FA 的 GQA 路径，输入 Q 为 Hq、K/V 为 Hkv。
3. 远端专家按 `(chunk,kv_head)` 组织，共享该 KV 头的所有选中 query 打包到同一专家。每个历史块/KV-head 至多打包一份 KV。
4. 远端行仍映射到 `p=token*Hq+query_head`，复用 CUDA 全局输出/LSE 合并。
5. grouped 远端专家可能有超过原序列长度的 query 行，单独计算 remote_max_seqlen，避免误用局部 FA 的长度上界。
6. 保留官方使用全局 O/LSE 的反向公式，扩展长度元数据；共享 KV 的梯度由打包的 autograd 路径汇总。

路由仍物化 F×Hq×T 的 gate/mask，并使用动态 nonzero 和 host 标量读取。本阶段不支持 CUDA Graph 全图捕获。

## 形状泛化和边界

CUDA 按 padded D=32/64/128/256 调度 warp，逐元素读写用真实 D 屏蔽；Triton 使用对应 padded arange 与 mask。Attention 入口校验 shape、dtype、同设备、head ratio、cu、最大长度与配置。

CUDA 独立合并接口补齐所有输入的同设备/shape 检查，并在原子建图前拒绝非法 mapping 范围。独立 API 默认检查容量；可信内部路由凭每个 query 至多 K-1 个远端贡献的上界免逐次同步检查。

## 正确性证据

- CPU 参考与契约：初轮 65 项通过；补齐命令行输入生成检查后共有 67 项 CPU 用例，含新的可微 FP64 grouped reference 与 gradcheck。
- 首轮 grouped GPU：82 项通过。含 32 个 D × 两种 dtype 的前向和 dQ/dK/dV。
- 最终完整回归：**305 项通过、2 项跳过**（307 个 collected 用例）；跳过项仅为双卡设备绑定，本批仅单卡授权。早期整体验证为 297 通过/2 跳过，随后增加长序列、CLI 输入和 mapping 类型检查，最终统一重跑。
- heads 覆盖：1/1、8/1、8/2、16/2、28/4、32/8。后面几组来自已有模型配置，但只使用随机输入。
- 独立 FP64：在小规模实际稀疏路由上，独立计算前向与一阶 dQ/dK/dV；不同于旧阶段只验证完整前向输出。
- 在 28/4 用例中，选块集合与复制 KV 后的官方路由完全相同；不将该测试外推为所有浮点 tie 输入的形式化保证。
- 因果、跨序列隔离、fallback、候选不足、非法 mapping、host 输入均有检查。
- 长序列补充：4 项全部通过，含 2048 tokens 的 28/4 不均匀 batch、2048 tokens 的 16/2 FP16、4096 tokens 的 16/1 FP16 D=80，以及 8192 tokens 的 32/8 BF16；每项比较输出和 dQ/dK/dV。
